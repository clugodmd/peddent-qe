DATA SCHEMA
================================================================================

Questions (questions.json):
  {
    "id": number,                    // Unique identifier
    "topic": string,                 // Topic (14 unique topics)
    "question": string,              // Question text
    "a": string,                     // Answer option A
    "b": string,                     // Answer option B
    "c": string,                     // Answer option C
    "d": string,                     // Answer option D
    "e": string,                     // Answer option E (optional)
    "answer": "a|b|c|d|e",          // Correct answer letter
    "explanation": string,           // Why answer is correct
    "source": string                 // Source document
  }

Progress (localStorage):
  {
    "questionId": {
      "attempts": number,            // Total attempts
      "correct": number,             // Correct answers
      "lastSeen": timestamp,         // Last study date
      "flagged": boolean,            // Marked for review
      "notes": string,               // User notes
      "nextReview": timestamp,       // Next review date (spaced rep)
      "easeFactor": number,          // SM-2 algorithm parameter
      "interval": number,            // Days until next review
      "timeSpent": number            // Seconds spent
    }
  }

Settings (localStorage):
  {
    "darkMode": boolean,             // Dark mode enabled
    "fontSize": "small|normal|large",// Font size setting
    "soundEnabled": boolean,         // (for future)
    "notificationsEnabled": boolean  // (for future)
  }
